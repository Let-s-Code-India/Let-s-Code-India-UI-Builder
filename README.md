## 📌 Overview
`let-S-Code-India-UI-Builder` transforms AI agents into world-class Senior Frontend Architects and Design System Engineers. It enforces strict mathematical, psychological, and accessibility standards to generate production-ready, highly responsive web interfaces and components using React, TypeScript, and Tailwind CSS.

## 🛠️ Core Engineering Pillars
- **Precision Color Architecture:** Strict 60-30-10 proportionality rules across 50 curated palettes.
- **Typography Systems:** Proportional font pairings sourced from Google Fonts with optimized scales and line-heights.
- **Surface & Layout Shaping:** Glassmorphism, Bento Grids, Neo-Brutalism, and Sci-Fi HUD spatial frameworks.
- **Atomic Component Suite:** Production-ready interactive elements with complete micro-interactions.
- **Visual Hierarchy & Depth:** Z-index layer stacks, Lucide/Phosphor icons, and 3D elevation shadows.
- **Rigorous Accessibility (WCAG AA/AAA):** Contrast compliance, keyboard navigation, and dark/light token switching.
- **The 20-Point Anti-AI Firewall:** Explicit prohibitions against generic AI slop, unoptimized layouts, and non-semantic DOM structures.
